## Shortcut

- `work/` = optional scratchpad, one file per topic. Create only when useful.
- `log/` = permanent record, one file per merged PR. Created by automation; fall back to by-hand if you prefer.

Frontmatter carries state. Automation uses the `branch:` field to link a scratchpad to its PR.

See `docs/automation-patterns.md` for the archiver implementation sketch used by this example.
